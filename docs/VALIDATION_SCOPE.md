# npuloop 검증 범위

이 문서는 정수 실행의 측정값과 가상 NPU 비용 추정을 구분하기 위한 기준이다. 실제 모빌린트 하드웨어 또는 고객 데이터에서 실행했다는 뜻이 아니다.

| 구분 | 근거가 있는 범위 | 확대해서 말하지 않을 범위 |
|---|---|---|
| NumPy ↔ C++ | 테스트에 포함된 모델·입력의 정수 코드 및 중간 텐서 일치 | 모든 입력의 정확성, 두 구현의 공통 오류 부재 |
| 파일 export ↔ 독립 실행형 C++ | 직렬화·역직렬화 후 시험 입력의 결과 일치 | 제삼의 독립 알고리즘 검증, 실제 NPU 실행 |
| E11 외부 대조 | 지정 TFLite reference 경로, conv(stride 1·2)·MEAN·fully-connected를 포함한 시험 모델, 1,000장 비교 | depthwise·add·softmax·LayerNorm 등 전체 연산자의 TFLite 일치 |
| E8 비용 대조 | SCALE-Sim과 공통 가정 아래 dense conv·linear 연산 사이클 비교 | DRAM 스톨·벡터 엔진·멀티코어·실제 실리콘 성능 |
| E13 Vela 대조 | 두 해석적 추정기의 차이(약 0.29–0.84배) | Vela도 실측이라는 주장, 특정 비용 항이 원인이라는 인과 확정 |
| E15 정확도·출력 코드 | 분류 모델 6종 × 방식 2종, 전체 테스트셋의 기존 저장 결과 | ±0.20%p 이내의 통계적 동등성, 모든 모델로의 일반화 |
| E15·E17 연산자별 국소 차이 | 고정 표본 배치의 교사 강제 측정. 종류 평균은 노드별 비율의 단순평균 | 전체 테스트셋의 모든 노드 조사, 텐서 크기 가중 평균 |
| E16 개입 | LayerNorm만 정수 연산으로 에뮬레이션했을 때의 결과 | 모든 연산자의 누적 교체가 불가능하다는 결론 |
| E17 밀집 출력 | 3층 ESPCN ×2, Imagenette 기반 초해상 조건 | 깊이가 원인이라는 확정, 더 깊은 모델의 불일치 하한 |

## 수치의 읽는 법

분류의 **top-1 정확도**, 두 실행의 **top-1 예측 일치율**, **출력 코드 불일치율**은 다른 지표다. 출력 코드가 다르다고 동일 비율의 분류가 틀린 것은 아니다. 국소 불일치율은 한 연산자의 입력을 맞춰 비교한 값이며 전파 불일치율과 가산 분해 관계가 아니다.

E15의 관측 정확도 차이 최대 0.20%p와 신뢰구간의 0 포함은 동등성 입증이 아니다. E16의 pc 교체 조건은 약 2.2 표준오차다. 같은 정수 실행을 기준으로 한 두 차이만으로 개입에 따른 정확도 예측 개선을 검정하지 않는다.

표 3.1에서 LayerNorm 이외 **종류 평균**은 1% 미만이지만, 풀링 **개별 노드**는 최대 2.697%다. E14의 18개 비교는 **3개 모델 × 3개 학습 반복 × 2개 반올림 모드(truncate/floor)**이며, 두 양자화 방식의 조합을 뜻하지 않는다.

## 2026-09-16 통합본의 실행 검증 범위

업로드한 전체 소스에 수정 사항을 적용한 **로컬 Linux 통합본**을 실행했다. 기본 전체 테스트는 147개 통과·4개 건너뜀이고, `make verify`에서 번들 체크포인트의 quickstart와 결과 JSON 기반 논문 표 재생성 검사도 완료했다. 두 학습된 번들 모델은 각각 시험 이미지 8장으로 NumPy·C++·파일 export·독립 C++ 실행기의 중간 텐서를 별도 대조했다. 상세 수와 로그는 [통합 검증 기록](INTEGRATION_REPORT.md)에 있다.

데모는 Chromium에서 오프라인 HTML로 로드하여 146개 컨트롤 조건과 20개 비용 프리셋·10개 인테이크 결과를 확인했다. 외부 글꼴 CSS는 비워 로컬 시스템 글꼴로 표시했다. 공개 GitHub Pages 접속이나 원격 배포를 검증한 것은 아니다.

이 결과를 모든 실험의 독립 재실행으로 합쳐 말하지 않는다. 전체 CIFAR-10·Imagenette 데이터와 전체 원본 학습 체크포인트는 업로드에 없었다. TFLite·SCALE-Sim·Vela 실험의 기존 JSON을 다시 읽고 표를 만들었지만 외부 도구 실험 자체를 새로 실행하지 않았다. 실제 NPU 하드웨어·모빌린트 SDK·Windows 네이티브 실행도 이번 검증 대상이 아니다.
