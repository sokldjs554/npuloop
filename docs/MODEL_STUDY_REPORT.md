모빌린트 신입 Deep Learning Research Engineer 공고의 핵심인 모델 수정·학습·경량화를 실제 데모와 실행 경로의 중심으로 옮겼습니다. 기준은 사용자가 제공한 공고 전문이며, 기존 정수 검증 연구도 모델 결과를 확인하는 기능으로 연결했습니다.

E6의 `int8_acc`는 모의 양자화로 표시하고, E9의 FP32 10,000장과 정수 2,000장을 구분합니다. QAT 이후 FP32나 일부 프리셋의 비용이 없는 경우 값을 만들어 채우지 않습니다. E17은 PSNR을 사용합니다.

## 새 학습 실행의 범위

번들 ResNet-20의 채널 제거율 0.25, 실제 학습 2 step·64장, 고정 시험 32장 조건으로 실행했습니다.

| 단계 | 로컬 정답 / 시험 이미지 | CI 정답 / 시험 이미지 |
|---|---:|---:|
| 기준 FP32 | 29 / 32 | 29 / 32 |
| 구조 수정 직후 FP32 | 22 / 32 | 22 / 32 |
| 회복 학습 후 FP32 | 24 / 32 | 24 / 32 |
| 모의 양자화 | 24 / 32 | 24 / 32 |
| NumPy 정수 엔진 | 24 / 32 | 23 / 32 |

각 실행에서 같은 시험 이미지로 단계를 비교했습니다. CPU·런타임 환경이 다른 로컬과 CI의 결과를 같은 실행으로 합치지 않습니다. 가상 `edge-10tops` 비용은 두 구조에서 34,417→30,025 사이클로 추정했습니다. 이 소규모 실행은 학습·평가 연결의 검증이며 전체 데이터 성능, 학습 수렴, 환경 간 비트 동일 재학습을 입증하지 않습니다.

로컬 실행의 JSON·설정·학습 로그는 `verification/model-study/run/`에 있습니다. 체크포인트와 정수 그래프 등 전체 출력은 명령을 실행한 출력 디렉터리에 생성됩니다. 전체 E1–E17 원본 학습을 다시 수행한 것은 아니며 실제 모빌린트 SDK·NPU 실측도 포함하지 않습니다. 실행 안내는 [STUDY_RUNNER.md](STUDY_RUNNER.md)를 따릅니다.
