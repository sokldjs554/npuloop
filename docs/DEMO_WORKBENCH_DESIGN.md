# npuloop 분석 워크벤치

## 범위
사용자의 전면 재구성 지시에 따라 공개 화면을 분석용 애플리케이션으로 교체한다. 대화체·질문형 제목·튜토리얼 단계·대형 마케팅 소개 영역을 사용하지 않는다. 첫 화면은 선택 조건과 진단 요약이다.

## 구조
모델 분석(요약/연산자/변경 비교/비용 설정), 정수 검증(E15 및 E16·E17), 실험 기록(E1–E17 원본 탐색), 재현 자료의 네 영역. 모든 스타일·스크립트·결과는 HTML에 인라인으로 포함한다. 새 네트워크/백엔드/학습 호출 없음.

## 데이터 경계
비용은 기존 JS 비용 모델의 브라우저 추정. 변경 비교는 E9의 동일 조건 저장값만 사용하고 사용자 비용 설정이 변경되면 과거 변경 결과와 혼합하지 않는다. E15의 10,000장/3,925장 전체 평가를 E9의 2,000장 결과와 구분한다. 누락된 결과는 빈 상태로 표시한다.

## 검증
새 데이터 계약 테스트의 실패를 먼저 확인한다. 모델 5종×프리셋 4종의 Python/JS 일치 검사를 보존한다. 새 화면 내 모든 메뉴·필터·모델·프리셋·사용자 설정·원본 자료 보기·다운로드·키보드·모바일을 브라우저로 확인한다. 결과 JSON·엔진·논문은 SHA-256으로 보호한다.
