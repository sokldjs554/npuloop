# 승인된 데모 구성

사용자가 채팅에서 승인한 방향: 대표 모델 분석을 메인으로 두고 연구·검증 자료를 분리한다.

- 첫 화면은 ViT-128/6 + edge-10tops-strict 사례로 시작한다.
- 모델 확인 → 문제 진단 → 변경 전후 → 최종 판단의 네 단계.
- 상단 메뉴는 모델 분석 데모 / 연구 결과 / 검증·재현 자료 세 개.
- 기존 실험과 도구를 제거하지 않는다. 상세 도구는 검증 영역의 접기/펼치기에 둔다.
- E9 저장 사례의 비용은 추정이고 정확도는 저장된 측정. 새 학습·NPU 실행을 흉내 내지 않는다.
- E9 INT8 2,000장과 E15 10,000장을 섞지 않는다. 누락된 변경 실험은 없다고 표시한다.
- 순수 HTML 파일을 더블클릭해서 작동. 외부 자바스크립트·API·웹폰트 없이 작동.
- 논문·연구 결과·코어 정수 엔진은 변경하지 않는다. 원격 저장소에는 반영하지 않는다.
