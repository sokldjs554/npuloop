# 자체 코드·표시 검토

외부 독립 리뷰가 아닌 로컬 검토 기록입니다.

- 수치 경로: 기존 비용 수식을 별도 모듈로 분리. 모델 5개/프리셋 4개 Python↔JS 노드별 일치 테스트 유지.
- 기록 경로: E9/E15 표본 및 출처 독립. 사용자 비용 설정의 결과를 기존 변경 후 기록과 혼합하지 않음.
- 원본 보호: 표시 변환은 읽기 전용. 126개 보호 파일 SHA-256 변화 없음.
- 소스 JSON 표시에 textContent 사용. HTML 문자열은 escape 처리. JSON 인라인 데이터의 '<'는 Unicode escape.
- 실험 표: E4의 variant/step/QAT 형태 차이 및 원본/변경 후 정확도 분리. E12 baseline/PTQ 필드 차이 검사.
- 탐색: 노드 검색/필터/정렬, 링크, 페이지 이동, 키보드와 skip link 검사.
- 모바일: grid min-width 전파를 막고 표만 내부 스크롤. 페이지 전체 가로 넘침을 숨겨 통과시키지 않음.
- 미구현 기능을 버튼으로 표시하지 않음. 업로드·실제 NPU 실행·재학습 UI 없음.
- 문서: README, 시작 안내, 데모 안내를 새 UI에 맞춤. 이전 검사 기록을 현재 결과로 표시하지 않음.
