# 연구 원고 — 검토된 장문판과 이전 초안

모빌린트 지원 자료로 연결하는 원고는 **`npuloop_thesis.pdf`**다. 2026-09-18에 E17의 두 깊이 결과, E13의 연산자별 격차 분해, E18(재양자화 축 × 시드 3개), E19(AdaRound), E20(ImageNet 규모)을 반영하고, 업로드된 `results/*.json`에서 표와 그림을 다시 만들어 32쪽으로 빌드했다. 저자는 윤기혁이며, **개인 연구 원고**다. 학술지 게재·채택이나 학위 취득을 뜻하지 않는다.

| 파일 | 상태와 용도 |
|---|---|
| `npuloop_thesis.tex` / `npuloop_thesis.pdf` | 현재 검토한 국문 장문판, 7장·부록 2개·영문 초록 |
| `npuloop_thesis_reviewed.pdf` | 위 PDF의 동일한 별칭 |
| `../docs/research/npuloop_thesis.pdf` | 데모에서 여는 동일한 PDF |
| `npuloop_esl.tex` / `npuloop_esl.pdf` | 4쪽 영문 단문판. 제출본으로 선택하지 않았으나 본문·표를 장문판과 같은 결과 파일에 맞춰 유지한다 |
| `npuloop_ko.tex` / `npuloop_ko.pdf` | 4쪽 국문 단문판. 위와 같다 |

단문판 3편은 표·그림 생성 소스를 공유하며, 2026-09-18 기준으로 본문 서술도 같은 결과 파일에 맞췄다. 다만 **제출본으로 선택한 것은 장문판 하나**다. 실제 학술 투고가 필요하면 선택한 원고의 내용·저자 정보·학회 규정을 별도로 확인해야 한다.

## 장문판 빌드

저장소 루트에서 실행한다. LuaLaTeX, `luatexko`, `adjustbox`, `titlesec`, TeX Gyre 및 Nanum 계열 글꼴과 Python의 NumPy·Matplotlib이 필요하다. 글꼴 파일은 배포 ZIP에 포함하지 않는다.

```bash
make paper-reviewed
```

이 명령은 `make_tables.py --lang ko`, `make_figs.py --lang ko`, `make_thesis.py`를 실행하고 LuaLaTeX를 3회 수행한 뒤 데모의 PDF 링크 대상도 갱신한다. **전체 논문 원본 모델을 새로 평가하는 명령은 아니다.** 저장된 JSON으로 표·그림을 재생성하고 문서를 빌드한다.

검사만 실행하려면 다음을 사용한다.

```bash
python tools/submission_quality.py --regenerate --report paper-quality-report.json
```

`.github/workflows/paper-quality.yml`에는 문서 검사와 장문판 빌드를 구성했다. 이번 검증은 로컬에서 수행했으며, 수정된 워크플로를 GitHub에 올려 실행하지 않았다. CI의 표 일치 검사도 독립적인 학습·평가 재현을 의미하지 않는다.

## 결과를 읽는 범위

E15의 분류 모델 6종·방식 2종에서 관측 정확도 차이는 최대 0.20%p이고 12개 신뢰구간이 0을 포함한다. 이는 사전에 정한 허용 범위 안의 통계적 동등성을 입증한 것이 아니다. 출력 코드 불일치 28.5–72.7%는 정확도와 다른 지표다.

E20은 Keras가 배포하는 ImageNet ResNet-50 가중치를 torch로 옮겨(Keras 대비 최대 확률 차이 1.1×10⁻⁶) 잰 것이다. **ImageNet 규모 그래프와 ImageNet 가중치이지 ImageNet-1k 검증셋 정확도가 아니다** — 검증셋은 재배포할 수 없으므로 이미지는 Imagenette 시험 분할이다. 따라서 top-1 절대값(72.41%)은 ImageNet 수치와 비교할 수 없다. 이 절이 주장하는 것은 정확도의 수준이 아니라 두 실행의 차이(|Δ|/SE ≤ 0.2)와 출력 코드 불일치(57.3–57.9%)다.

E18은 E7의 재양자화 축을 모델당 체크포인트 3개·test 전체로 다시 잰 결과다. **등급(무손실/손실/붕괴)은 시드를 넘어 유지되지만 크기는 유지되지 않는다**는 것을 보이며, 따라서 E7의 단일 시드 %p 수치는 등급 판정용으로만 남긴다. E19는 AdaRound의 결과이며 **음성(null)**이다. 계층별 재구성 오차는 194개 계층 전부에서 줄었지만(중앙값 0.52배) top-1은 6개 조합 전부에서 |Δ|/SE ≤ 1.2로 움직이지 않았다. 이는 AdaRound에 대한 반박이 아니라 8비트 가중치 조건에 대한 관찰이다.

E16은 LayerNorm 단독 교체가 전체 출력 코드 일치를 만들지 못했다는 결과다. 모든 연산자를 누적 교체하는 방법이 불가능하다는 결론을 내리지 않는다. E17의 초해상 PSNR 관측 차이는 conv 3개에서 최대 약 6.4×10⁻⁴ dB, conv 9개에서 약 2.9×10⁻³ dB이며 픽셀 코드 불일치율(6.3–18.2%, 69.2–73.0%)과 구분한다. 두 깊이는 폭 구성을 고정한 대조군이고, 깊은 쪽의 float PSNR이 0.12 dB 낮으므로 **품질 개선이 아니다**. 깊이는 두 점에서만 쟀으므로 이 관계의 함수 형태는 주장하지 않는다.

노드별 국소 불일치는 고정 표본 배치에서 측정했고, 종류별 평균은 노드 비율의 단순평균이다. TFLite 외부 대조는 지정 conv·MEAN·fully-connected 시험 모델에 한정되고, 가상 NPU 비용 모델은 실제 실리콘 성능이 아니다.
